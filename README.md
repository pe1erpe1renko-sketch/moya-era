# Моя Эра

> **Программистам:** пошаговая передача и чек-лист приёмки — `docs/PEREDACHA-PROGRAMMISTAM.md`.

Сервис самопознания: матрица судьбы, натальная карта, дизайн человека, нумерология, таро, совместимость. Next.js 16 · React 19 · Tailwind 4 · Supabase · KIE (Claude) · ЮKassa.

## Что внутри

## Модель продукта

- **Единица учёта — профиль человека.** Тариф задаёт, сколько людей открыто: Базовый — 1, Семейный — 5, Практик — без ограничений. Подписка открывает все системы и все типы разбора по датам своих людей.
- **Кредиты — только на сообщения наставнику.** Чтение разборов без счётчиков. Пакет входит в тариф, докупается отдельно.
- **Бесплатно, без регистрации:** центральный аркан, схема из 25 точек, первый вопрос в каждой из 12 сфер. Замок — внутри разбора, не перед ним.
- Тарифы и цены лежат в таблицах `plans` и `credit_packs` — меняются `UPDATE`-ом без деплоя. Цифры в них — стартовые, для обсуждения.

## Запуск локально

```bash
npm ci
cp .env.example .env.local     # заполнить, что есть
npm run dev                    # http://localhost:3000
npm test                       # тесты движка матрицы и эфемерид
npm run build                  # сборка
```

Без переменных Supabase сайт работает в **демо-режиме**: авторизация и данные живут в браузере, все разборы открыты, тексты — заглушки и пять эталонных. Так можно посмотреть продукт целиком до подключения базы. В прод так не выпускать.

## Развёртывание — по шагам

### 1. GitHub

```bash
git init            # если ещё нет
git add -A && git commit -m "Моя Эра"
git remote add origin https://github.com/<аккаунт>/moya-era.git
git push -u origin main
```

### 2. Supabase

1. Создать проект на supabase.com.
2. SQL Editor → выполнить файлы из `supabase/migrations/` **по порядку** (пять файлов). Или через CLI: `supabase db push`.
3. Authentication → Providers → Email: включить. Подтверждение почты — по желанию (если включено, после регистрации нужно перейти по ссылке из письма).
4. Project Settings → API: скопировать `URL`, `anon key`, `service_role key`.

### 3. KIE (нейросеть)

1. Ключ — на kie.ai/api-key.
2. Проверить, что модели доступны: `LLM_API_KEY=… node scripts/llm-check.mjs`. Если KIE называет модели иначе — поправить `LLM_MODEL_TEXTS` / `LLM_MODEL_CHAT`.
3. Наполнить базу текстов **до запуска** (иначе первые посетители будут ждать генерацию):
   ```bash
   node scripts/fill-texts.mjs --dry      # объём: ~3 300 текстов
   node scripts/fill-texts.mjs            # 1–2 часа, можно прерывать и продолжать
   ```
   Аркан дня, личный год и образы генерируются лениво, по запросу.

### 4. Vercel

1. Import Git Repository → выбрать репозиторий. Framework — Next.js, ничего менять не надо.
2. Environment Variables — все из `.env.example`. `SUPABASE_SERVICE_ROLE_KEY`, `LLM_API_KEY`, `YOOKASSA_*` — без префикса `NEXT_PUBLIC_`, они серверные.
3. Deploy. Домен — Settings → Domains.
4. `NEXT_PUBLIC_SITE_URL` поставить равным боевому домену (для canonical и OG).

### 5. ЮKassa (когда юристы отдадут документы)

1. В кабинете ЮKassa: HTTP-уведомления → адрес `https://<домен>/api/payments/webhook`, событие `payment.succeeded`.
2. `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` — в Vercel.
3. До этого момента кнопка «Оплатить» честно отвечает «оплата подключается».

**Автопродление.** При оплате тарифа сохраняется способ оплаты (`save_payment_method`). Само списание раз в период — отдельная задача: cron (Vercel Cron → `/api/billing/renew`), который создаёт платёж по сохранённому `payment_method_id` за день до `current_period_end`. Не реализовано — намеренно, до появления оферты с условиями автосписания.

### 6. Яндекс.Метрика

Создать счётчик, номер — в `NEXT_PUBLIC_METRIKA_ID`. Цели (события уже отправляются): `calc_submit`, `reading_view`, `paywall_open`, `signup`, `person_add`, `checkout_open`, `checkout_pay`, `chat_message`.

## Правила, которые нельзя нарушать

- `src/lib/matrix/matrixEngine.js` и `contentPositions.js` не редактировать: методика сверена с четырьмя сервисами до последней цифры; тесты `npm test` должны быть зелёными после любой правки рядом.
- Идентификаторы слотов не переименовывать — на них висят тексты в базе.
- При изменении промптов поднимать `PROMPT_VERSION` в `prompts.js`: старые тексты перегенерируются, а не смешиваются.
- Никаких зачёркнутых цен, таймеров и «осталось N мест» — это позиция продукта.
- Тексты нигде не обещают предсказание событий.
- Эфемериды только `astronomy-engine` (MIT). Swiss Ephemeris, его обёртки, Moshier-JS и `libephemeris` под запретом: AGPL/GPL.
