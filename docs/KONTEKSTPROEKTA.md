# Контекст проекта «Моя Эра» — прочитать первым делом

Этот файл — память между сессиями. Если ты открыл репозиторий впервые, прочитай его целиком, прежде чем что-либо делать.

---

## 1. Что это за проект

Портал-агрегатор по эзотерике. Шесть систем самопознания: матрица судьбы, натальная карта, дизайн человека, нумерология, таро, совместимость. Флагман — **матрица судьбы**, остальные системы разворачиваются по её образцу.

Главная задача продукта — **удержание**. Заказчик формулирует так: «чтобы клиент возвращался постоянно, ежедневно». Сайт зарабатывает на ежемесячной подписке, а не на разовых продажах.

Позиционирование из брифа: **салон-обсерватория**. Салон — атмосфера и ритуал, обсерватория — настоящие расчёты с объяснением, откуда взялось каждое число. Максимализм в эстетике, минимализм в утверждениях.

**Продукт до нас.** Первую версию делала Александра в Lovable, потом перенесла на Next.js. Дизайн, тексты и архитектура данных у неё сильные — их сохраняем. Продукта за фасадом не было: авторизация подделана на localStorage, платежей нет, разборы не генерировались. Полный разбор её работы — в проекте заказчика, документ «Аудит и доработки».

## 2. Заказчик и как с ним работать

Пётр (RomanPETROS). Не программист. Ставит задачи голосом, мыслит продуктом и деньгами, в технике разбирается слабо — GitHub освоил в этой работе с нуля.

**Правила общения, которые он попросил явно:**

- **По одному шагу за раз.** Он выполняет, отчитывается, задаёт вопросы, и только потом следующий шаг. Не вываливать простыни инструкций.
- **Не забегать вперёд.** Не делать того, о чём не договорились. Он прямо сказал: «прежде чем ты сразу пересобираешь файлы — не надо, мы ещё не закончили».
- **Не тратить токены впустую.** Сначала обсудить, что делаем, получить подтверждение, потом делать.
- **Инструкции — как для новичка.** Конкретные кнопки, что увидишь на экране, а не «зайди в настройки».

Он ценит, когда ему объясняют «почему», а не только «что нажать». И заранее предупреждают о рисках.

## 3. Утверждённые решения (не пересматривать без него)

**Архитектура — уровневая модель.** Шесть систем на верхнем уровне, внутри каждой свои типы разбора. «Совместимость» — это тип разбора внутри системы, а не седьмая сущность: совместимость по матрице, синастрия по натальной карте, композит по дизайну человека. На главной остаётся как витрина.

**Единица оплаты — профиль человека.** Тариф задаёт, сколько людей открыто: Базовый — 1, Семейный — 5, Практик — без ограничений. Подписка открывает все системы и все типы разбора по датам своих людей. Цены в таблице `plans`, меняются без деплоя. Текущие цифры стартовые, для обсуждения.

**Кредиты — только на сообщения наставнику.** Это единственный расход, растущий с числом пользователей. Расчёты — арифметика, тексты разборов кэшируются навсегда, аркан дня — максимум 22 генерации в сутки на весь сервис, AI-образы собираются из готовых картинок. Чтение оплаченного — всегда без счётчиков. Наценка на кредиты — минимум ×4–×5.

**Нейросети — через KIE** (посредник, оплата из РФ, Anthropic-совместимый endpoint). Тексты разборов — Claude Opus (пишутся один раз, качество важнее цены). Чат — Claude Haiku 4.5. DeepSeek заказчик отверг.

**Название «Моя Эра» оставляем**, проверку по ФИПС пока не делаем.

**Юридические документы** готовят юристы. На сайте остаются заглушки, программисты заменят.

**Ключи и подключение сервисов** — работа программистов, не заказчика. Но передаём им только полностью готовый прототип.

## 4. Что уже сделано

Матрица судьбы реализована как флагман:

- Движок расчёта перенесён без изменений из отдельной проработки. Тесты `npm test` зелёные.
- **Постоянные адреса разборов**: `/matrica/13-07-1998`, `/sovmestimost/дата/дата`, `/dengi/дата` и остальные десять типов плюс `/prognoz/`. Страницы кэшируются, бесплатные тексты уходят в HTML для индексации. **Ни у одного из тридцати разобранных конкурентов этого нет** — главная возможность проекта.
- Октаграмма из 25 точек с четырьмя слоями и зумом на телефоне. Двенадцать сфер, 92 вопроса, первый в каждой сфере открыт бесплатно.
- Исследовательские блоки с полем даты внутри карточки, «Кого посмотрим дальше?», карта здоровья по чакрам, аркан дня, театр загрузки.
- Supabase: люди, тарифы, подписки, кредиты, тексты, чат — миграции с RLS. Без ключей сайт работает в демо-режиме.
- Кабинет: аркан дня, личный год, календарь месяца, список людей с лимитом тарифа.
- Наставник: потоковый чат через KIE, кредиты, блок безопасности.
- Тарифы, checkout, ЮKassa с вебхуком и идемпотентностью.
- Мобильный первый экран починен, sitemap, robots, OG-картинки, Метрика с восемью событиями. Выдуманные отзывы убраны.

**Инфраструктура настроена:** GitHub → Vercel, автодеплой при пуше в `main`. Сайт живёт на **moya-era.vercel.app** в демо-режиме.

Тесты в `npm test` сверяют движок с эталоном NASA JPL DE421 на 24 датах 1931–2029 (`fixtures/jplDe421.ts`, генератор `scripts/ephemeris-reference.py`). Новая миграция `20260904120000_birth_place_coordinates.sql`: у `profiles` и `people` столбцы `birth_place_id`, `birth_lat`, `birth_lon`, `birth_tz`. Перевод местного времени в UTC (`localTime.ts`) на встроенной базе поясов, проверен тестами на 22 случаях советской истории и на переводах часов. `resolveBirthMoment` даёт точность расчёта: exact / noon (время неизвестно, полдень) / date_only (место не распознано). Источник GeoNames (CC BY 4.0) указан в подвале. Данные выгрузки берутся из npm-пакета `cities-500-structured` (сайт GeoNames из среды Claude недоступен). Крым и Севастополь в подписи показываются без страны («Симферополь, Крым»), потому что GeoNames относит их к Украине; если заказчик хочет иначе, менять в `placesIndex.ts`. ## 5. Что дальше

**Очередь 3 — механики возврата.** Ради них всё и затевалось, без них ежемесячная подписка не живёт: человек прочитал разбор за вечер и отменил.

- AI-образы: карточка-талисман собирается на canvas из 22 готовых иллюстраций арканов (не генерируется нейросетью — дорого и стиль плывёт). Семь тем. Первый образ бесплатно для всех, публичная страница образа с кнопкой «Рассчитать свою матрицу» — единственный бесплатный канал привлечения.
- Облачко-подсказка: только на страницах разбора, не раньше 90 секунд, только когда человек остановился, максимум три за визит, крестик закрывает навсегда.
- Telegram-бот: вечерняя рассылка аркана **на завтра**, тексты из той же базы, что и сайт.
- Автопродление подписки (cron), когда появится оферта с условиями автосписания.

**Очередь 4 — остальные пять систем. В работе, начата 04.09.2026.**

Эфемериды: **`astronomy-engine` (MIT)**. Заменила `libephemeris` из первоначального плана: та оказалась библиотекой на Python 3.12+ и под **AGPL-3.0-only** (Apache-2.0 стояла по ошибке только в пре-релизах rc2–rc8, они отозваны с PyPI). Swiss Ephemeris, любые обёртки над ним (в том числе WASM) и Moshier на JS под запретом: AGPL/GPL. `astronomia` (MIT) допустима только как перекрёстная проверка в тестах, в прод не тащить. Точность astronomy-engine сверена с NASA JPL DE421: худшее расхождение 18″ при градусе зодиака в 3600″ и линии дизайна человека в 3375″. Библиотека без файлов данных, 116 КБ, считает и на сервере, и в браузере — значит, бесплатный расчёт на странице дизайна человека возможен (в брифе его закрыли, потому что «в браузере не считается»).

Часовые пояса: встроенная база Node (tzdata) проверена на советской истории по одиннадцати городам СССР: декретное время 1930, летнее время 1981–1991, отмена декретного в 1991 и возврат в 1992, реформы 2011 и 2014, местное среднее время до 1930. Отдельная библиотека не нужна. Нужен справочник мест: GeoNames офлайн (CC BY 4.0, источник указать на сайте), русские названия и поиск по русскому вводу, Россия и СНГ подробно, остальной мир — крупные города. Из песочницы Claude сайт GeoNames не качается (прокси даёт 403), брать через зеркало на GitHub или просить заказчика разрешить домен.

Дизайн человека: Design-дата ищется численно как момент, когда Солнце было на **88 градусов долготы раньше**, а не «88 дней назад»: разброс реально 87–92 суток (проверено: 26.07.1990 → 25.04.1990, 91,8 суток).

Утверждённый бесплатный объём (04.09.2026), по принципу матрицы: схема бесплатна, толкования по подписке, замок внутри разбора, а не перед ним.
- Натальная карта: круг карты с положениями планет виден всем без регистрации. Бесплатно читаются Солнце (по дате) и Луна с асцендентом (если введены время и место). Остальные планеты, дома, аспекты — подписка.
- Дизайн человека: бодиграф с определёнными центрами виден всем. Бесплатно — тип и стратегия. Авторитет, профиль, каналы, ворота — подписка.
- Время рождения неизвестно: считать на 12:00 и честно показывать, что асцендент, дома и всё, что от них зависит, не определены. Ничего не выдумывать.

Шаги очереди. По одному, каждый — отдельный коммит, следующий только после «дальше» от заказчика:

4. Дизайн человека: ворота, каналы, центры, тип, стратегия, авторитет, профиль, крест, настоящий бодиграф, калькулятор, кабинет, тексты — **сделан**.

Перед шагами 3 и 4: сверить весь расчёт целиком (положения планет, асцендент, дома) с astro.com или другим независимым источником минимум на 20 контрольных датах, обязательно включая рождения в СССР (декретное время, летнее время 1981–1991, чехарда 1991 года). Для дизайна человека на тех же датах сверить тип, авторитет, профиль и Design-дату с открытым калькулятором. Результаты сверки зафиксировать в тестах.

**Очередь 5 — рост.** Граф «мои люди», справочник с отдельной страницей на каждую сущность, фасетные теги, PDF, вход через VK/Google, гарантия возврата.

## 6. Правила, которые нельзя нарушать

- `src/lib/matrix/matrixEngine.js` и `contentPositions.js` **не редактировать**. Методика сверена с четырьмя внешними сервисами до последней цифры, тесты — контроль. Заказчик сказал: методика закрыта.
- Идентификаторы вопросов (`slot.id`) не переименовывать — на них висят тексты в базе.
- Меняешь промпты — поднимай `PROMPT_VERSION`, иначе старые и новые тексты смешаются.
- **Никаких зачёркнутых цен, таймеров обратного отсчёта и «осталось N мест».** Весь рынок работает на фальшивом дефиците, мы принципиально нет — это и позиция продукта, и условие эквайринга.
- Тексты нигде не обещают предсказание событий. От этого зависит и приём платежей, и реклама.
- Тяжёлые арканы переименованы: Смерть → Перерождение, Дьявол → Искушение, Башня → Обновление.
- Блок безопасности в промпте наставника (что делать при признаках тяжёлого состояния человека) не сокращать и не переписывать.
- Эфемериды только `astronomy-engine` (MIT). Swiss Ephemeris, обёртки над ним, Moshier-JS и `libephemeris` под запретом: AGPL/GPL.
- Правила очереди 4 (от заказчика): один шаг — один коммит, после шага остановиться и ждать «дальше»; перед коммитом `npm test` и `npm run build` зелёные; коммит и пуш сразу в `main`, Vercel выкатывает сам; миграции только новыми файлами; ключи, Supabase и платежи не настраивать — это сделают программисты.
